RMTools

Aplicativo mobile desenvolvido em Flutter para criação e exportação de fichas de RPG em PDF.

Sobre o Projeto

O RMTools é uma aplicação voltada para jogadores de RPG que desejam criar fichas de personagens de forma rápida e organizada. O aplicativo permite preencher todos os dados iniciais de um personagem e gerar um PDF pronto para consulta, compartilhamento ou impressão.

O foco da aplicação está na criação da ficha inicial do personagem, servindo como uma ferramenta prática para preparação de campanhas e sessões.

Funcionalidades

- Criação de fichas de personagens
- Cadastro de atributos e características do personagem
- Controle de pontos disponíveis durante a criação da ficha
- Validação das regras de distribuição de pontos
- Geração de fichas em PDF
- Interface intuitiva para dispositivos móveis

Tecnologias Utilizadas

- Flutter
- Dart
- Biblioteca de geração de PDF

Como Funciona

O usuário define os parâmetros iniciais do personagem, distribui seus pontos de acordo com as regras do sistema utilizado e, ao finalizar o processo, pode exportar a ficha completa em formato PDF.

Limitações Atuais

Atualmente o aplicativo é focado exclusivamente na criação inicial da ficha.

Não estão disponíveis funcionalidades como:

- Evolução de personagens ao longo da campanha
- Ganho de novos pontos após a criação
- Progressão de níveis
- Atualização automática de fichas já finalizadas

Objetivos do Projeto

- Aplicar conceitos de desenvolvimento mobile com Flutter
- Trabalhar com gerenciamento de estado e formulários complexos
- Implementar geração dinâmica de documentos PDF
- Criar uma ferramenta útil para jogadores de RPG

Melhorias Futuras

- Sistema de progressão de personagens
- Edição de fichas já criadas
- Armazenamento em nuvem
- Compartilhamento entre jogadores
- Histórico de alterações
- Suporte a múltiplos sistemas de RPG
